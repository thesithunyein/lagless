Lagless pool fee on Unichain, live reading…

When Base moves, Unichain LPs start charging more about two seconds later.

The same token pair trades on Base and Unichain. After a price move on Base, the Unichain pool quotes a stale price and arbitrageurs take the difference from its LPs. Lagless watches Base from a Reactive Omni contract and raises the Unichain pool's fee while the gap is open, so that arbitrage pays LPs instead.

Same trades, two pools

After each Base move, the same arbitrage trade runs against two Unichain pools with identical liquidity: the Lagless pool and a control pool that always charges 0.30%. The only difference is the fee the LPs collect.
